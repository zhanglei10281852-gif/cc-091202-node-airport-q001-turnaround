# 航班过站运行资料服务

该仓库整理短停航班的保障节点、依赖关系和运行事件样例，并提供一个最小 Node.js HTTP 服务供本地联调。所有业务时刻均采用带偏移量的 ISO 8601 字符串，航班航段和航空器注册号分别标识运行任务与实际执行飞机。

`fixtures/context.json` 记录计划节点及三条到达顺序不同的保障上报。样例只用于说明字段、时间语义和关联方式，不代表机场的实时生产数据。

## 运行

需要 Node.js 20 或更高版本：

```bash
npm test
npm start
```

服务默认监听 `3000` 端口，`GET /health` 返回进程状态。也可以执行 `docker compose up --build` 启动容器，使用 `APP_PORT` 调整宿主机端口。

本地环境变量写入 `.env`，日志、依赖目录和任何运行凭据都不应提交到仓库。
